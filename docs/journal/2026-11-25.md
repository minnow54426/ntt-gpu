# Prepare the Ada rental handoff

## Outcome

Separated the rental runner, OpenFHE reference replay and analysis changes
from the research drafts. Prepared the source and the eight benchmark
workloads for an RTX 4080 SUPER batch.

## Reasoning

The runner requires a clean checkout so timing records can name the source
revision. The Git bundle lets the rental restore that checkout. The prepared
vectors and reference arrays let the conversion benchmark reuse the exact
OpenFHE answers computed on the Mac.

## Changes

The handoff pairs the source with the prepared inputs, the CUDA/NVTX access
probe from November 24 and the
[batch instructions](../next-gpu-rental.md#run-the-queue-as-one-batch).
The queued work includes the two 40-tower public-call repeats, a 40-tower
conversion trace and analysis on the Mac after the archive is collected.

## Verification

The RTX 4080 SUPER plan accepted all eight vector and reference sets. The
analyzer revalidated 160 paired operation rows and 12 resident repeat rows
from the November 24 GPU archive. The staged source passed 33 documentation
tests, 18 lesson tests and both static site builds. A clean CPU/OpenFHE build
passed all 34 CTest entries, including the tooling suite.

## Open questions

The next instance still needs a real Nsight access check. The handoff includes
source and inputs. Linux CUDA executables and pinned OpenFHE need to be built
for the rental image. The 5090 still needs separate hardware validation.

## Next step

Restore the clean checkout and verify the handoff before starting a paid
run. On the rental, check Nsight access first, then run the native batch.
Download and verify the evidence before ending the rental.
