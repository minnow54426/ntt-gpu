# Prepare more work before renting

## Outcome

Added Shoup constant multiplication and a reusable coefficient-domain
approximate basis-conversion plan. The plan preserves the unreduced CRT sum,
prime order and canonical residues required by pinned OpenFHE.

The new native probes join the NTT and resident-chain checks in the
[next rental batch](../next-gpu-rental.md). At preparation time, native execution
was pending. The [completed Ada run](#native-gpu-batch-completed) is recorded
below. The roadmap stays at P2/D11.

## Reasoning

The M1 Pro can establish the arithmetic, parameter tables and exact expected
arrays before provisioning. Shoup multiplication prepares each fixed
multiplier once. Each conversion target coefficient is independent, allowing
a simple first CUDA kernel with one output per thread.

The target-product reduction retains the reference 128-bit remainder path.
Native profiling will guide later optimization. Full resident ModUp/ModDown
composition remains a later deliverable.

## Verification

On the M1 Pro, all 29 CTests passed, including the broader conversion test's
107,675,648 residue comparisons against pinned OpenFHE. Its matrix covers all
five ring dimensions from 4,096 through 65,536, all four benchmark prime
widths, source counts 1/3/40, four patterns and both conversion directions.

The independent Python conversion oracle passed 334 cases, including 1,057
coefficients that distinguish approximate conversion from canonical CRT.
The arithmetic oracle checked 19,170 results including Shoup products.
The Hybrid graph and standalone ModUp/ModDown tests passed with the new
converter checked at each lift. AddressSanitizer and UndefinedBehaviorSanitizer
also passed the host arithmetic and conversion probes. The native test callers
passed host syntax checks. All 52 tooling tests passed, including candidate
sanitizer failure stopping collection before timing.

## Native GPU batch completed

Used the supplied rental server for the prepared CUDA work. The device reported
RTX 4080 SUPER, compute 8.9, 32,760 MiB and driver 595.71.05. CUDA was 12.8.
CMake 3.22 could not configure CUDA C++20; installing CMake 3.31.6 resolved that
configuration failure. Pinned OpenFHE was built as a dependency. Standalone CPU
tests and CPU performance measurements stayed on the M1 Pro.

The native source was an isolated clean snapshot, `0f2df64`, of the current
workspace based on `587598a`. The record contains a full source bundle, the
original workspace archive, exact dependency revision and their provenance.

Both the group-twiddle and legacy builds passed all 11 selected CTests,
including two fixture generators per build. Each build passed 20 sanitizer
stages across memcheck, racecheck, initcheck and synccheck. The new Shoup,
standalone conversion and resident-path checks passed. The conversion fixture
compared 107,675,648 residues against OpenFHE in each build. Both schedules
also compiled the CUDA targets and native probes for sm_120.

The paired sweep saved 48 validated measurement jobs across N=4,096/65,536,
K=3/40 and 30/60-bit primes. The three recorded scopes were GPU public calls,
CUDA events and the resident interface. Each used two warmups and ten samples.
After observing host-call variability, recorded an order-balanced resident
repeat at N=65,536/K=3/60-bit, with five warmups and 50 samples per operation
in each of four runs. Detailed performance interpretation remains local work.

Nsight Systems captured the resident timeline and exported its statistics.
Nsight Compute returned `ERR_NVGPUCTRPERM`; hardware counters remain unavailable
on this provider. The timeline includes session setup, so whole-trace totals
need care when interpreting timings that exclude setup.

Downloaded the complete 3.7 MiB archive into
`build/gpu-session-20261119/`. Verified its SHA-256, extracted it locally, then
rechecked all measurement hashes and records, sanitizer statuses, repeat
hashes and the timeline. The local verification record is
`verified-results.json`. Told the user that the rental can stop after this
verification. Further analysis and notebook checks run on the M1 Pro.

P2/D11 remains open for primary RTX 5090 evidence, actual driver/context failure
handling and hardware-counter profiling. Full resident ModUp/ModDown
composition and GPU Hybrid key switching remain later deliverables.
