## Reasoning

The earlier handoff pins `2b262aa`, before the runtime cleanup. Copying its
build records would not establish a matching build for the refactored code.
A separate clean checkout keeps the release source stable while the journal
and website are updated. Restore the manifest's `source_commit`; a later
documentation commit on `main` does not change the frozen release.
