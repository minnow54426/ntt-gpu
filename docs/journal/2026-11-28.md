## Broaden Hybrid parameter coverage offline

The original Hybrid fixture uses one five-Q configuration with three towers
per digit. Added a separate `--parameter-matrix` gate to catch assumptions
about that configuration without changing the fixed benchmark inputs.
All polynomials have N=65,536. Three configurations use scaling/first-prime
settings of 30/31, 50/60 and 59/60 bits with digit group sizes 2, 1 and 3.
Their special-prime counts are 2, 2 and 4 respectively. An attempted scaling
setting of 60 was rejected by pinned OpenFHE, whose 64-bit build requires
that setting to be below 60; the supported upper-width case uses 59.

The matrix has 15 diagnostic cases covering every active Q count from one
through five, plus six generated-key cases at the level endpoints. Each
compares digit arrays, QP accumulators, reduced contributions, the core
adapter and transactional two/three-component wrappers with OpenFHE. Dense
inputs include zero, one and q−1 entries. Each context must also distinguish
canonical-CRT substitution and incorrect reduced-level P-key offsets.
Independent BigInteger intermediate checks and the sum-before-ModDown
negative test remain active. Logs retain exact primes, roots and backend.

Registered host and CUDA CTests for the new gate. The collector rejects
missing host/native matrix registrations before running checks, and the
CUDA test has the `gpu` label so offline testing excludes its execution.
The batch will run it for both schedules at the next rental.

All 35 CPU/OpenFHE CTests passed. A final rerun of the matrix passed all
21 cases and 209,059,840 residue comparisons with the backend explicitly
recorded as `host_simulation`. Both CUDA schedules compiled the final native
fixture for sm_89 and sm_120. The registration checks confirmed the new
native gate and its `gpu` label. Tooling, documentation and lesson checks
passed 89, 33 and 18 tests respectively. These checks establish offline
correctness and compilation; native matrix execution is still pending.

The documentation builder validated 56 notebook pages and the six-page
public guide. Chromium checked all 25 public pages at 1440, 1024, 375 and
320 pixels, including contrast, search and all four SVG/Three.js explorers.
The detailed matrix explanation, runbook and journal also passed desktop
and phone checks. The website states that this is additional CPU coverage
and that the corresponding GPU checks remain queued.

The new source changes fixtures and gate collection; it does not change
arithmetic kernels or the rotation fixture format. The earlier `4fb89d7`
handoff remains immutable and does not include this new matrix. A later
source freeze must include it before renting; earlier build evidence cannot
be relabelled as evidence for that revision. D11/P2, native Hybrid acceptance
and broader encrypted-operation/production coverage remain open.
