## Reasoning

An installed profiler and container root access do not prove that the host
allows GPU counters. CUDA/NVTX tracing and Nsight Compute metrics must be
checked separately on the actual instance. The verification should happen
before spending the rental on the long test and measurement batch.

For beginners, the hard questions are concrete: which two numbers form a
butterfly, which addresses a thread owns, what a prime tower contains, and
which arrays cross the CPU–GPU boundary. Exact labelled diagrams and short
calculations answer those questions before the proofs. Optional 3D views
help inspect structure; dated results, prices, contracts and journal entries
remain readable text and tables rather than synthetic performance scenes.

## Changes

The rental queue now specifies the required device/tool metadata, a small
CUDA/NVTX trace, an actual SM/L2/DRAM counter capture, and retained commands,
logs and reports. The rental procedure links to that TODO, and AGENTS.md
requires future rental work to follow it. The batch's later operation
profiles remain separate from this early manual access check.

The new [teaching models](../site-assets/visual-models.mjs) cover an eight-value
group-twiddle negacyclic NTT, all sixteen forward stages of the 65,536-position
thread layout, a four-value RNS polynomial and full-size byte accounting, and
resident versus separate-call transfers. Small examples are explicitly
distinguished from full-size arrays. The models do not implement Hybrid key
switching, approximate basis conversion or native CUDA execution.

The [presentation module](../site-assets/visual-lessons.mjs) starts with an
interactive SVG diagram and exact text values. A reader can request a local
Three.js 0.160.1 view and rotate it using a labelled keyboard-accessible slider.
There is no animation loop or runtime CDN request. Controls remain usable
without WebGL; context loss returns to the diagram. Without JavaScript, the
initial static diagram and explanation remain. Wide diagrams scroll inside
their frames so phone labels retain a readable size.

Kept Three.js's MIT license and download provenance beside the pinned library.
