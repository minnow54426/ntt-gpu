# Compare GPU rentals for the first native session

## Outcome

Completed a [GPU rental market survey](../gpu-rental-market-survey.md) for this
project's first native CUDA session. Compare RunPod Community and verified
Vast.ai RTX 5090 offers; retain RTX 4090 as the control. No GPU was rented or
tested. D11 remains open and no roadmap gate advances.

## Reasoning

The cheapest advertised GPU-hour need not be the cheapest usable experiment.
Driver/toolkit compatibility, build resources, selected disk, network charges,
setup time and Nsight counter permissions can change the decision. Offline
preparation makes a short on-demand session more practical than continuous
rental or an early reservation.

## Verification

Official pricing, billing and NVIDIA permission sources were reviewed on
November 13, 2026. The Vast query returned 64 records: 33 RTX 5090 and 31 RTX
4090 offers. Its response reported no truncation; the survey describes a sample,
not an exhaustive inventory or guaranteed booking. AutoDL's current GPU offer
and all specific hosts' hardware-counter permissions remain unverified.

All 23 documentation unit tests and 14 Node interaction/math tests passed.
The build validated local links and fragments for 30 HTML pages, including
nine journal entries. Chromium passed 120 page/width checks at
1440/1024/375/320px: English content, rendered mathematics, no page-wide
overflow and no script or HTTP errors. The new article and journal passed
computed text-contrast checks; section navigation and search worked. Desktop
and phone screenshots were inspected, and wide price tables were adjusted for
horizontal scrolling on phones.

All 64 saved offer records were checked against every stated query filter;
the article's counts, minima, maxima and medians match the snapshot, and each
record's compute plus default storage equals its reported total. This research
establishes no GPU correctness or performance result. Website export,
deployment and live verification follow the source commit.
