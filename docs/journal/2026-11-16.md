# Restore the website's earlier visual design

## Outcome

Restored the earlier website design from Git history at the user's request.
The portfolio uses its Sunlit Paper palette, Anton/Space Grotesk typography,
photo-filled lettering and full-width photo grids. The research notebook
returns to its earlier green and paper theme with an expanded page directory.
Current articles, journals, native GPU results and roadmap state are preserved.

Later the same day, the user asked to apply the portfolio theme to the NTT-GPU
pages. The notebook now shares Sunlit Paper backgrounds, burnt-orange and
forest-green accents, Anton headings and Space Grotesk body text. The earlier
restoration remains recorded above; the original design is also backed up on
the website repository's `backup/old-website-design` branch.

## Reasoning

The November 11 shared blue/white redesign changed the visual identity beyond
what the user wanted. Restore the presentation from the preceding revisions
without reverting the repository or losing later engineering work. Keep the
English text, readable lesson panels, keyboard navigation and current controls.

The follow-up explicitly requests a common theme. Keep the portfolio's visual
identity while tuning type sizes, code surfaces, tables and controls for long
technical articles. Load the theme from source so exports retain it.
