# Make the butterfly implementation inspectable

Reconstructed on 2026-11-08 from commit `751e723` and verification recorded
during that work.

## Outcome

Connected the formula for evaluating a polynomial to the small paired
operations called butterflies and to the CPU loops that execute them.
Added an eight-value VS Code example so readers can pause and inspect each step.

## Reasoning

Splitting the input into even and odd positions gives two smaller transforms.
Two outputs reuse their results with opposite signs, producing a butterfly.
For multiplication modulo x^N+1, evaluate at odd powers of a primitive
2N-th root. Rendering those formulas makes the derivation
easier to read. The site includes KaTeX, its formula renderer, so equations do not require
a separate network download. For debugging, Xcode’s LLDB DAP connection
replaced the CodeLLDB adapter that crashed in the recorded setup.
