# Make the butterfly implementation inspectable

Reconstructed on 2026-11-08 from commit `751e723` and verification recorded
during that work.

## Outcome

Connected the direct NTT sum, butterflies, negacyclic twisting, and CPU loops.
Added an N=8 VS Code example for source-level debugging.

## Reasoning

Even/odd subtransforms share terms across opposite output indices; their sign
difference produces the butterfly. Odd powers of a 2N-th root provide the
negacyclic evaluation points. Rendering those formulas makes the derivation
easier to read. Locally bundled KaTeX removes a network dependency for math.
Xcode LLDB DAP replaces the observed crashing CodeLLDB adapter.
