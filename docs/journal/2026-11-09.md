# Make the 4096-point CUDA schedule tangible

## Outcome

Added a standalone HTML learning page explaining the current forward CUDA
schedule using a concrete 4096-coefficient polynomial and one RNS limb.
No CUDA implementation or roadmap gate changed.

## Reasoning

Line-by-line reading obscures the overall work distribution. The explanation
starts with data ownership: columns for the four far stages, then rows for the
eight near stages. Interactive stage, block, and thread selection shows how
butterfly pairs change, including inactive threads in the baseline schedule.

## Changes

- [4096-point NTT work distribution](../ntt-4096-work-distribution.html).
- Registered the learning page in the site catalog.
- Exported the existing interactive explanation with a standalone runtime and
  added context about synchronization, shared memory, and limb-major storage.
- Formatting follow-up: replaced the exported iframe/runtime with a small,
  self-contained lesson. Added consistent notebook typography, numbered
  sections, jump links, side-by-side pass descriptions, and an integrated
  light-themed explorer. The page now scrolls as one document; controls and
  pass descriptions stack at narrow widths. Mathematical content and thread
  mapping are retained.
