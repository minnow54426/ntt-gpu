# Make the 4096-point CUDA schedule tangible

## Outcome

Added a standalone HTML learning page explaining the current forward CUDA
schedule using a concrete 4096-coefficient polynomial and one RNS limb.
No CUDA implementation or roadmap gate changed.
Later follow-up: completed the D1 index/memory map for both target extremes
and advanced the working-day tracker to D2; the P1 architecture exit gate
is still open.
Subsequent D2 work completed the column index/twiddle proof and exhaustive
stage-helper checks; the tracker now points to D3 inverse-column work.

## Reasoning

Line-by-line reading obscures the overall work distribution. The explanation
starts with data ownership: columns for the four far stages, then rows for the
eight near stages. Interactive stage, block, and thread selection shows how
butterfly pairs change, including inactive threads in the baseline schedule.
