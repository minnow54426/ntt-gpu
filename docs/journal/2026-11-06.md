# A roadmap with explicit gates

Reconstructed on 2026-11-08 from the linked commits and reports.

## Outcome

Added the 95-working-day integration plan, GPU selection survey, and clearer
implementation naming and formatting.

## Reasoning

The sequence is NTT, base conversion, Hybrid key switching, then OpenFHE.
Each step requires its own exactness and performance gate. Encrypted inference
follows integration. RTX 5090 is the provisional primary target and RTX 4090
the control; the [hardware report](../gpu-selection-survey.md) requires
workload-specific benchmarks before claiming a winner.
