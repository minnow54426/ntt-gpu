# Freeze the OpenFHE NTT and DCRT representation contract

## Outcome

D7's NTT/DCRT boundary is documented against pinned OpenFHE 1.6.1. The tracker
advances to D8, the Hybrid operation graph; P1's architecture gate stays open.
The website export includes the previously unpublished D3–D6 work and this D7
contract, with the shared section navigation retained.

## Reasoning

A round trip alone can conceal a matching forward/inverse permutation or scale
error. D7 checks every evaluation address against closed-form monomials and
independent inverse basis vectors. A real three-tower DCRT object verifies
parameter order and packing without assuming a contiguous OpenFHE allocation.

The pinned source distinguishes SetFormat (conditional conversion), SwitchFormat
(always conversion), SetValues (data plus label), and OverrideFormat (label only).
DCRT OverrideFormat changes only the outer label. RootOfUnity selects the minimum
primitive root, but the FTT cache lookup does not compare roots on a cache hit;
consistent imported roots are part of this contract.
