# Exactness before GPU speed

Reconstructed on 2026-11-08 from the linked commits and reports. This records
documented outcomes, not a contemporaneous account of experiments.

## Outcome

Added tests that compare every transform value with a specific OpenFHE
1.6.1 revision. Also added a survey of GPU NTT techniques and a plan for
repeatable performance measurements.

## Reasoning

CKKS decryption gives approximate numbers. Similar decrypted answers can
hide different polynomial arrays, so the required test compares every
transform value at the same array position.
The [survey](../gpu-ntt-survey.md) identifies modular division, strided access,
and host transfers as optimization candidates, not measured speedups.

## Verification

The gate covers N=4096 through 65536, 50- and 59-bit moduli, and deterministic
input patterns. The CPU schedule simulator is a separate correctness check.
Real GPU execution remained outstanding.

## Open questions

How much time does the GPU spend reducing integer products modulo a prime?
How much does it waste fetching widely spaced column values? Answering
these questions requires profiling on an identified GPU.
